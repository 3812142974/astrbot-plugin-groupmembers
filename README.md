# astrbot-plugin-groupmembers

将 QQ 群成员（头像 + 昵称 + QQ 号）整合成**一条合并转发消息**发出来的 AstrBot 插件。

适用于 OneBot v11 协议端（如 **NapCat**），在群聊中使用。

## 指令

| 指令 | 作用 |
| --- | --- |
| `/群成员头像` | 把**整个群**所有人各做成一个转发节点（头像 + 昵称 + QQ）。 |
| `/群成员头像 5` | 随机抽 **5** 个人做合并转发。 |
| `/群成员头像 @A @B` | 只收录被 **@** 的这些人。 |
| `/群成员头像 @A @B @C 2` | 在 @ 的人里随机抽 **2** 个。 |
| `/群成员头像at @A @B` | 另一个指令，语义同上：@ 谁就只收录谁（可加数字随机）。 |

> 数字参数表示「随机几个人」；@ 参数表示「只收录这些人」；都不带就是全群。

## 安装

1. AstrBot 后台 → 插件市场 → 从 GitHub 安装，仓库地址填：
   `https://github.com/3812142974/astrbot-plugin-groupmembers`
2. 或把本仓库放进 AstrBot 的 `plugins/` 目录后重载插件。

## 说明 / 注意

- 头像通过 `https://q.qlogo.cn/headimg_dl?dst_uin=<QQ>&spec=640` 获取，
  单张下载失败也不影响其他人（该成员节点只显示文字）。
- 合并转发里每张头像都会被转成 base64 内嵌，**群越大体积越大**。
  如果群人数很多导致发送缓慢或被 OneBot 端拒绝，请把 `main.py` 顶部的
  `AVATAR_SPEC` 调小（例如 `100`），或尽量少用「全群」模式。
- 需要机器人具备「获取群成员列表」的权限（NapCat 默认在群内即可）。
